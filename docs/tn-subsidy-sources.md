# Tamil Nadu tariff and subsidy references

- Official TNERC Tariff Order 2025: https://tnerc.tn.gov.in/Orders/files/TO-Order%20No6300620252131.pdf
  - LT-IA domestic bi-monthly slabs in the order include 0–400 at ₹4.95/unit, 401–500 at ₹6.65/unit, 501–600 at ₹8.80/unit, 601–800 at ₹9.95/unit, 801–1000 at ₹11.05/unit, and above 1000 at ₹12.15/unit for FY 2025–26.
  - The order states the domestic category is partly subsidised and that domestic consumers had no tariff hike for the stated control period.
- Official TNPDCL tariff schedule page: https://www.tnpdcl.org/en/tnpdcl/billing-services/schedules-tariff/
- Official TNPDCL homepage / consumer information: https://www.tnpdcl.org/
- Subsidy rule implemented from the supplied project specification: eligible domestic consumers using 500 units or less in a complete two-month cycle receive 200 free units; consumers above 500 units receive 100 free units. The code deliberately applies this only to residential/domestic bi-monthly cycles and tests exactly 500 and 501 units.

The project keeps the deterministic tariff calculator separate from the supplied AI bill model. Model output is not treated as proof that the current subsidy rule was already included in model training.
